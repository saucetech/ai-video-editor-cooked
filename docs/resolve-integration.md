# Local Resolve source-cut adapter

The macOS Lua Console connection and native source-cut creation/update were verified in Resolve 21.1.1.10 (free edition) on 2026-10-24. The adapter also retains its Python transports for installations that support them. Verification and limits are recorded below.

## Repeatable workflow

Trigger: continue an existing cooked edit in Resolve while retaining editable original media and manual work.

Inputs: an edit folder with `decisions.json` (kept source seconds), `report.json` (`source`, `fps`, integer `[start, end)` `frames`), a readable original file, and optionally `plan.json`. Relative source paths resolve against the edit folder. A plan must have the current cut duration. This adapter follows the original-source export contract in `plugins/ai-editor/skills/style-edit/scripts/export_nle.py` rather than importing a flattened render.

1. Open a dedicated Resolve project. Call `ai_editor.resolve_bridge.status()`; this reads connectivity and does not select a timeline.
2. In cooked, open **Connect Codex → Resolve & Higgsfield → Set up local Resolve connection**. Open **Workspace → Console** in Resolve, paste the displayed `dofile(...)` command and press Return. Do this once per Resolve session; the Console runs the helper until you stop it. Free Resolve 21.1 can omit `.py` scripts and refuse menu execution, so restarting or changing Python paths does not fix that case. The Lua menu wrapper is installed for editions where menu execution works. Keep this checkout in place. No scripting preference is changed. To disconnect, use **Stop Resolve connection** in cooked; wait for its acknowledgement. Inspect incomplete timelines before reconnecting.
3. Call `create_timeline(Path(edit_folder), name=None)`. It imports the original and creates a new `cooked. <folder>` timeline. It never appends to an existing timeline. On completion it restores the previously selected timeline when one existed. Resolve's project manager saves the current project, including any other existing unsaved project changes; use a dedicated project for isolation.
4. Review the timeline in Resolve. The adapter supports source cuts and constant punch zooms through `ZoomX`/`ZoomY`. It splits clips at static punch boundaries. Animated/eased/push zooms are omitted with a warning. Original audio follows Resolve's normal append behavior; audio cleanup/fades from cooked's rendered cut are not reproduced.
5. If only managed zoom scale values changed in cooked, call `update_timeline(Path(edit_folder))`. It finds the timeline by unique ID without changing the current timeline. It checks all managed video/audio clip identities, source references/paths, trims, placement, duration, speed, enabled state, prior managed zoom values and timeline settings before writing anything. It sets only `ZoomX`/`ZoomY`; manual Pan, Tilt, grading and other properties are preserved.
6. Conflicts return `ok: false` and a reason. Recutting, replacing the original, changing the timebase, adding/removing zoom boundaries, or manually changing managed clips requires a separate edit folder and new timeline. The adapter does not rebuild over the existing timeline. Repeated Create is rejected while a manifest exists.

Deliverables: a dedicated native timeline and `resolve-manifest.json` in the edit folder. The manifest includes project/timeline IDs, source path/stat, rational frame rate, clip mapping, managed zoom values and verified API snapshot. It is local project data, not a repository fixture. No media or runtime secrets belong in Git.

Acceptance: exact source ranges and assembled frame counts, matching source/timeline frame rates, a saved ready manifest, managed zooms readable back through the API, preserved manual unmanaged properties, and conflicts detected before any write. Real acceptance also requires inspecting generated footage and audio in a dedicated Resolve project. Offline fakes alone do not establish native correctness or editorial quality.

Feedback: report the returned error code plus the manifest `state`, and the smallest synthetic reproduction. Keep the original timeline. An `incomplete` manifest means an operation might have partially applied; inspect it in Resolve before any retry. Do not delete a `.resolve-bridge.lock` until confirming no operation is running. No unknown editing request is automatically replayed through another transport.

## Interface and transport

Public functions return JSON-safe dictionaries:

- `status()` returns `{connected: bool, version: string|null, message: string}`.
- `create_timeline(edit_dir: Path, name: str|None = None)` and `update_timeline(edit_dir: Path)` return `{ok: true, timeline_id, timeline_name, manifest, clips, warnings, message}` or `{ok: false, code, message}`.
- `install_internal_bridge(runtime=None, scripts_dir=None)` returns `{ok, path, lua_path, console_command, message}`. `stop_local_connection()` explicitly stops the Lua helper. The optional arguments support isolated tests; normal callers use the default user directories.
- `start_embedded(resolve, runtime=None)` is called only inside Resolve; it returns connection status without a credential. `stop_embedded()` stops that interpreter's service.
- `ResolveBridge(resolve=fake)` injects a vendor-shaped object for tests. `ResolveBridge(command=[...], runtime=..., timeout=...)` allows an explicit installed runtime/test transport.

The primary macOS transport uses `resolve_lua.py` and `resolve_helper.lua`. The helper runs in Resolve's built-in Lua 5.1 Console. The tested free installation has a live `resolve` object and bundled LuaJIT `ffi`, while `io`, `require` and Python are unavailable. The helper uses that bundled FFI only to read/write fixed mailbox filenames under `$AI_EDITOR_HOME/resolve-lua` (default `~/.ai-video-editor/resolve-lua`). This folder is mode `0700`; generated helper, requests, responses and lock files are `0600`. There is no network listener, shell or request-selected file operation. JSON data is parsed without `loadstring` or evaluation.

An explicit per-type vendor method allowlist and session-scoped object references let the existing Python timeline logic operate through this transport. Request UUIDs, generation IDs, fractional deadlines, duplicate suppression and an exclusive operation lock prevent stale/repeated dispatch. A timeout, malformed result or vendor exception poisons the session: no restoration RPC is sent, and a persistent quarantine lock blocks later work. A stale helper also blocks fallback through Python. **Stop Resolve connection** removes quarantine only after that helper generation acknowledges shutdown; never remove its lock merely to retry a possibly accepted mutation. A stopped helper can be restarted with the Console command. If Resolve crashed before acknowledgement, inspect the project and incomplete manifest, ensure the process has exited, then remove only that stale `resolve-lua/client.lock` as explicit manual recovery.

The retained Python in-process service binds only `127.0.0.1`, uses a random bearer credential in a `0600` descriptor, rejects browser-origin requests, and accepts three fixed adapter actions. Without an active/stale Lua session or internal service, native calls may use Resolve 21.1+'s bundled `ResolvePython` subprocess. External scripting requires support in the installed edition and configuration. Default executable discovery currently supports macOS only; it is not the working connection on the tested free installation.

Source intervals remain exclusive-end internally. Native Resolve 21.1.1.10 also treats `AppendToTimeline.endFrame` as exclusive, so the append dictionary uses `endFrame = exclusive_end`; the returned API duration/start/left offset is checked before reporting success. NTSC rates such as 29.97 are retained as `30000/1001` in the manifest and set using Resolve's nominal rate string. Decisions are rounded using the report's actual FPS and checked against report integer frame ranges, avoiding stale-cut imports.

## Remaining limits

The tested path is macOS free Resolve 21.1.1.10 via the Lua Console. Older Resolve versions, Studio transports, Windows/Linux, NTSC native playback, long-form production footage and crash recovery have not been validated in real use. Unit coverage includes NTSC conversion; that is separate from native acceptance. The working Console helper needs starting once after each Resolve restart.

Advanced captions/graphics, music/sound cues, rendered audio cleanup, animated source zooms, speed ramps, multicam, multiple-original joined sources, variable-frame-rate conformance and native source-timecode edge cases are outside this slice. Manual keyframes on managed zoom properties cannot be exhaustively inspected through this static property API; do not update managed zooms after adding such animation. Static native zooms and original-audio frame placement passed the synthetic test. Animated transforms/keyframes, real-footage audio quality and editorial quality still need representative footage verification. Source identity uses path, size and modification time, not a full media hash. Unmanaged properties are left untouched, but this is not a guarantee against every possible Resolve editing operation. No quality or time-savings claims are made.
