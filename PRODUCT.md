# GenMedia Editor

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
The founder is building a personal AI editing workflow, with later use by other creators. No real footage has been supplied for creative-quality testing yet.

## Product Purpose
Review AI edit decisions, preview source cuts, approve a revision, and create a separate DaVinci Resolve timeline for finishing. The user requested the name GenMedia Editor and an elevated interface consistent with GenMedia.

## Operating Context
Local Python servers and vanilla HTML/CSS/JavaScript. Codex connects using the user's ChatGPT account. Resolve uses a local Lua helper. Higgsfield provides optional asset integration. Original media and account credentials stay outside this repository.

## Capabilities and Constraints
Source passage keep/remove, protected holds, planning notes, emphasis notes, saved previews, approval, and separate Resolve timelines are implemented. Static zoom is applied in Resolve. Captions, graphics, generated B-roll placement, and complete AI Edit Suite feature parity remain incomplete. Existing media paths, API routes, stored revisions, and native timelines must remain usable through the rebrand.

## Brand Commitments
User explicitly requested GenMedia Editor, elevated design, and removal of the previous generic AI appearance. GenMedia's founder records leave final fonts, palette, and motion settings undecided. The user subsequently selected an Apple-inspired dark Liquid Glass theme and requested Aura.build design references. This commitment applies to the editor; it is not a universal GenMedia brand standard.

## Evidence on Hand
The synthetic edit-board sample validates workflow mechanics only. Existing setup and integration verification is recorded under docs/ and the private GenMedia project record. No savings, creative-quality, or market-superiority benchmark is established.

## Product Principles
- Put the video and editing decisions first.
- Keep approval and native timeline creation explicit.
- Preserve real capability limits in the UI.
- Protect the user's time and existing work.
